# ФормПоток: Текст

Офлайн-программа для распознавания печатного русского текста в PDF, PNG и JPEG. Исходная страница и полученный текст открыты рядом: ошибки можно исправить до сохранения TXT. Документы остаются на компьютере.

[English](README.en.md)

## Что умеет

- Обрабатывает очередь файлов на CPU и сохраняет её между запусками.
- Показывает строки с низкой уверенностью, помогает найти их на странице и запоминает отметки о проверке. В тексте есть поиск.
- Сохраняет исправленный текст отдельным TXT или собирает несколько документов в один файл с выбранным порядком и заголовками.
- По желанию сохраняет проверенный документ в локальный набор эталонов. Его можно использовать для сравнения версий OCR по CER и WER.

Проверка встроена в работу с документом: от исходной страницы до исправленного файла не нужно переходить в другой редактор. [Как устроено распознавание](docs/RECOGNITION.md) и [что показали сравнения](docs/OCR_COMPARISONS.md). Приведённые там OCR-замеры сделаны на синтетических страницах, а не на случайной выборке документов пользователей.

## Исходный код и запуск

Доступен [снимок исходного кода](https://github.com/greggubarev/formpotok-text/releases/tag/source-2026-11-01). Проверенного публичного установщика пока нет. Для сборки интерфейса нужны Windows x64 и .NET SDK 10; для распознавания также нужны локальный OCR-runtime и модели. Порядок сборки и тестирования указан в [руководстве разработчика](docs/DEVELOPMENT.md).

Для первого прогона используйте [пример документа с контрольным текстом](examples/README.md). [Инструкция пользователя](docs/USER_GUIDE.md) описывает очередь, проверку, экспорт и типичные ошибки.

## Ограничения

- До 20 МиБ на файл, 20 страниц на PDF и 20 млн пикселей на страницу.
- Рукопись, повреждённые сканы и сложные таблицы требуют ручной проверки.
- TXT содержит текст, но не восстанавливает вёрстку исходного документа. Автоматического извлечения транспортных полей в этой программе нет.

Рабочие копии и правки хранятся в `%LOCALAPPDATA%\FormPotok\Text`. Распознавание не требует сервера. Техническая статистика выключена по умолчанию и даже после включения остаётся локальной. Не публикуйте документы или результаты распознавания, если они содержат чужие данные. [Подробнее о хранении](docs/USER_GUIDE.md#данные-и-конфиденциальность).
